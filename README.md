# LOCKDOWN — Windows PC sürümü

[**Windows oyununu indir (45,34 MiB ZIP)**](https://github.com/Kaanmeteunal1/nexus-data/raw/refs/heads/lockdown-download/LOCKDOWN-PC-Windows.zip)

ZIP dosyasını tamamen çıkar ve içindeki `LOCKDOWN.exe` dosyasını aç. Oyuncunun Godot veya Node.js kurması gerekmez. Windows 10/11 x64 içindir.

[Kaynak kodları indir](https://github.com/Kaanmeteunal1/nexus-data/raw/refs/heads/lockdown-download/LOCKDOWN-PC-Source.zip) · [Oyun görüntüsü](gameplay.png) · [SHA-256 doğrulama değerleri](SHA256SUMS.txt)

Üç tesis atmosferi, altı mini oyun, serbest alıştırma ve gardiyan/mahkûm rollerine sahip yerel ağ odaları içerir. Ayrıntılar ve kontroller Windows ZIP dosyasındaki `PC-SURUMU.md` belgesindedir.

Godot 4.6.3 ile gerçek yerel Windows yürütülebilir dosyası üretildi. Windows üzerinde çalıştırma testi bu ortamda yapılmadı; Linux dışa aktarımı, oyun kuralları, arayüz ve iki işlem arasında ENet bağlantısı test edildi. İnternetten oynamak için erişilebilir UDP 9277 gerekir; otomatik bağlantı aktarım hizmeti kurulmuş değildir. Bu sürüm, hedeflenen AA düzeyinde tamamlanmış bir ticari ürün olarak değerlendirilmemelidir.

Bu dal, hazırlanmış dosyaların indirilebilmesi içindir; `main` dalı değiştirilmedi.
